プライバシーポリシー

最終更新: 2026年10月3日

FyfAI(以下「本ツール」)は、個人の運営者が自分のYouTubeチャンネルへ動画を投稿・管理するために使う個人用ツールです。本ポリシーは、本ツールがGoogle(YouTube)のAPIを通じて取り扱う情報について説明します。

1. 取得する情報

運営者本人がGoogleアカウントで許可した範囲に限り、次の情報にアクセスします。

  • 運営者本人のYouTubeチャンネルの情報(チャンネル名・ID)。
  • 運営者本人のチャンネルに付いたコメント(本文・投稿日時・投稿者の表示名)。
  • OAuth の認証情報(アクセストークン・更新トークン)。

本ツールは、運営者本人以外のGoogleアカウントの情報を取得しません。

2. 利用目的

  • 作成した動画を、運営者本人のチャンネルへアップロードするため(youtube.upload)。
  • 運営者本人のチャンネルのコメントを確認し、返信または保留にするため(youtube.force-ssl)。
  • 運営者本人のチャンネルのコメントの一部を、運営者が公開する動画の中で紹介するため。紹介するときは、コメントの本文だけを使い、投稿者の名前・アイコンは表示しません。

上記以外の目的には利用しません。広告、プロファイリング、販売、第三者への提供は行いません。

3. 保管

認証情報(トークン)は、運営者のパソコン内にのみ保存し、公開しません。コメントなどのYouTubeのデータは、上記の目的に必要な間だけ扱います。動画の中で紹介したコメントの本文は、その動画の一部として運営者のチャンネルで公開されますが、それ以外のデータを運営者のパソコンの外へ公開・提供することはありません。

4. Google API サービスのユーザーデータに関するポリシーへの準拠

FyfAI が Google API から受け取った情報の利用と、他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(制限付き使用の要件を含む)に準拠します。本ツールは YouTube 利用規約および Google プライバシーポリシーにも従います。

5. 許可の取り消しとデータの削除

Googleアカウントの アカウント権限のページから、いつでも本ツールへの許可を取り消せます。許可を取り消した後、本ツールはそのアカウントのデータにアクセスできなくなります。保存済みの認証情報の削除を希望する場合は、下記の連絡先までお知らせください。

6. 変更

本ポリシーを変更する場合は、このページを更新します。

7. お問い合わせ

GitHub の問い合わせ窓口(https://github.com/yamanysnb/fyfai-legal/issues)からご連絡ください。

Privacy Policy

Last updated: October 3, 2026

FyfAI ("the Tool") is a personal tool used by one individual operator to publish and manage videos on the operator's own YouTube channels. This policy describes the information the Tool handles through Google (YouTube) APIs.

1. Information we access

Only within the scope the operator authorizes with their own Google account, the Tool accesses:

  • Information about the operator's own YouTube channel (channel name and ID).
  • Comments posted on the operator's own channel (text, timestamp, and the author's display name).
  • OAuth credentials (access and refresh tokens).

The Tool does not access information from any Google account other than the operator's own.

2. How we use it

  • To upload finished videos to the operator's own channel (youtube.upload).
  • To review the comments on the operator's own channel and reply to them or hold them for review (youtube.force-ssl).
  • To feature some of the comments from the operator's own channel in videos the operator publishes. Only the text of a comment is used; the commenter's name and avatar are not shown.

We do not use the information for any other purpose. We do not use it for advertising or profiling, and we do not sell it or share it with third parties.

3. Storage

Credentials are stored only on the operator's own computer and are never published. YouTube data such as comments is handled only as long as needed for the purposes above. The text of a comment featured in a video is published as part of that video on the operator's channel; no other data is published or provided outside the operator's own computer.

4. Compliance with Google API Services User Data Policy

FyfAI's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. The Tool also complies with the YouTube Terms of Service and the Google Privacy Policy.

5. Revoking access and deleting data

You can revoke the Tool's access at any time on your Google Account's permissions page. After access is revoked, the Tool can no longer reach that account's data. To request deletion of stored credentials, contact us at the address below.

6. Changes

If this policy changes, this page will be updated.

7. Contact

Please contact us via GitHub Issues (https://github.com/yamanysnb/fyfai-legal/issues).
